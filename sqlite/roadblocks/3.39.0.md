# SQLite 3.39.0 Roadblocks

**Release Date:** 2022-06-25

## Changes
- **RIGHT and FULL OUTER JOIN support** (major feature)
- Enhancements to date/time functions
- Query planner improvements for aggregate queries
- New SQLITE_DBCONFIG_DEFENSIVE option
- Performance improvements for IN operators with subqueries
- Enhanced EXPLAIN QUERY PLAN output

## Potential Roadblocks
| Change | Risk | Impact |
|--------|------|--------|
| **RIGHT and FULL OUTER JOIN** | **Critical** | **select.c, where.c, sqliteInt.h**: This is a major feature adding new JOIN types. Requires significant changes to query processing, code generation, and query planner. Will likely conflict with Comdb2's custom JOIN handling and query optimization. |
| **Query planner aggregate improvements** | **Medium** | **select.c, where.c**: Changes to how aggregate queries are optimized. Could conflict with Comdb2's aggregate handling. |
| **IN operator subquery optimization** | **Medium** | **where.c**: Enhanced optimization for IN with subqueries. May interact with Comdb2's query rewriting. |
| **EXPLAIN QUERY PLAN enhancements** | **Low** | **vdbe.c**: More detailed query plan output. Low risk unless Comdb2 parses EXPLAIN output. |
| **Date/time function enhancements** | **Low** | **func.c**: Minor improvements to existing functions. Low risk. |

## Action Items
1. **CRITICAL**: Review RIGHT and FULL OUTER JOIN implementation
   - Audit select.c changes extensively
   - Check Join structure modifications in sqliteInt.h
   - Review code generation in where.c and vdbe.c
   - Verify no conflicts with Comdb2's existing JOIN logic
   - Test all combinations: LEFT, RIGHT, FULL, INNER joins

2. **HIGH PRIORITY**: Test query planner changes
   - Review aggregate query optimization changes
   - Test complex aggregate queries with GROUP BY

3. **MEDIUM PRIORITY**: Validate IN operator optimization
   - Test IN with subqueries
   - Verify compatibility with Comdb2's query rewriting
   - Check performance doesn't regress

4. **Testing**:
