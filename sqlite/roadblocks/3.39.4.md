# SQLite 3.39.4 Roadblocks

**Release Date:** 2022-09-29

## Changes
- Bug fixes for issues discovered in 3.39.3
- Fix for performance regression in 3.39.0
- Fix for incorrect row count with FULL OUTER JOIN
- Fix for potential crash with malformed CREATE TABLE
- Security fix for potential buffer overflow

## Potential Roadblocks
| Change | Risk | Impact |
|--------|------|--------|
| **Performance regression fix** | **Low** | Restores performance from 3.38.x. Important update. |
| **FULL OUTER JOIN row count fix** | **Low** | Correctness fix for FULL OUTER JOIN. |

## Action Items
No significant roadblocks expected. This is primarily a bug fix release.

**Recommended**: Important update if using 3.39.x series. Fixes performance regression and includes security fix.
