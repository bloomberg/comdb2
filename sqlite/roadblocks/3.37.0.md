# SQLite 3.37.0 Roadblocks

**Release Date:** 2021-11-27

## Changes
- STRICT tables (new table option enforcing type constraints)
- Enhanced RETURNING clause with better trigger integration
- Improved error messages
- Query planner improvements for IN operator
- Datetime function enhancements

## Potential Roadblocks

| Change | Risk | Impact |
|--------|------|--------|
| STRICT tables | High | Requires parser changes in **parse.y** (new keyword), schema changes in **build.c**, and type checking in **vdbemem.c** and **insert.c**. May conflict with Comdb2's existing type system and 80+ custom keywords. |
| RETURNING enhancements | Medium | Further changes to **vdbe.c**, **insert.c**, and trigger handling. Builds on 3.35.0 RETURNING implementation. |
| IN operator optimizations | Medium | Changes to **where.c** and query planner. May interact with Comdb2's WHERE clause optimizations. |
| Type checking improvements | Medium | Modifications to **vdbemem.c** for STRICT table enforcement. Could conflict with Comdb2's value handling and type conversion logic. |

## Action Items

1. **STRICT Tables Analysis**
   - Review parse.y for "STRICT" keyword conflicts with Comdb2's 80+ keywords
   - Analyze build.c schema changes against Comdb2's table creation logic
   - Evaluate vdbemem.c type checking against Comdb2's type system
   - Decision: Adopt STRICT tables or maintain separate path?

2. **RETURNING Enhancement Review**
   - Diff against 3.35.0 RETURNING implementation
   - Test trigger interaction with RETURNING clause
   - Verify compatibility with Comdb2's trigger system

3. **Type System Compatibility**
   - Test vdbemem.c changes with Comdb2's value handling
   - Verify no regression in type conversion behavior
   - Validate insert.c type checking against Comdb2's constraints

4. **Query Planner Testing**
   - Test IN operator performance with Comdb2 workloads
   - Validate where.c changes don't break Comdb2 optimizations
   - Benchmark IN operator queries

5. **Integration Testing**
   - Full regression suite
   - Type constraint testing
   - RETURNING clause with triggers
   - IN operator query tests
