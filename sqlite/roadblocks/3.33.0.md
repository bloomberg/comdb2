# SQLite 3.33.0 Roadblocks

**Release Date:** 2020-08-14

## Changes
- UPDATE FROM syntax (joins in UPDATE statements)
- Improved query planner for joins with OR constraints
- Decimal extension for exact decimal arithmetic
- Enhanced EXPLAIN QUERY PLAN output
- Performance improvements in the byte-code engine

## Potential Roadblocks

| Change | Risk | Impact |
|--------|------|--------|
| UPDATE FROM (join syntax) | **High** | Major changes to **parse.y**, **build.c**, **update.c**, **vdbe.c**. Comdb2's distributed UPDATE logic may not support joining tables in UPDATE. Requires significant testing and potential redesign for distributed execution. |
| OR constraint join optimization | **Medium** | Modifications to **where.c**, **whereInt.h**. May interact with Comdb2's query planner and affect join order selection. |
| EXPLAIN QUERY PLAN enhancements | **Low** | Changes to **explain.c**, **vdbe.c**. Should be compatible but verify output is useful for debugging Comdb2 queries. |
| VDBE performance improvements | **Low** | Optimizations in **vdbe.c**, **vdbeaux.c**. Should be beneficial but needs testing with Comdb2's VDBE modifications. |

## Action Items

1. **UPDATE FROM Analysis** (High Priority)
   - Review parse.y grammar changes for UPDATE FROM syntax
   - Analyze build.c and update.c modifications for join processing
   - Assess compatibility with Comdb2's distributed UPDATE mechanism
   - Determine if UPDATE FROM should work across distributed tables
   - Design test cases for local and distributed UPDATE FROM

2. **Build.c Integration**
   - Review code generation for UPDATE with joins
   - Verify compatibility with Comdb2's triggers and constraints
   - Test with Comdb2's cascading updates and foreign keys
   - Ensure proper transaction handling

3. **VDBE Testing**
   - Identify new opcodes for UPDATE FROM
   - Test execution with Comdb2's modified VDBE
   - Verify proper row locking and isolation
   - Test with indexes and constraints

4. **Query Planner OR Optimization**
   - Review where.c changes for OR constraint handling
   - Test with Comdb2's custom index selection
   - Verify performance improvements apply to distributed queries
   - Benchmark complex OR conditions

5. **EXPLAIN Integration**
   - Test EXPLAIN QUERY PLAN with Comdb2's query structures
   - Verify output includes Comdb2-specific information
   - Ensure remote query plans are visible
