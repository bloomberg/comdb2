# SQLite 3.41.0 Roadblocks

**Release Date:** 2023-02-21

## Changes
- **Performance improvements** - Major focus on query performance
- Query planner enhancements for CROSS JOIN detection
- Faster LIKE and GLOB operators with optimized algorithms
- Improved memory usage in aggregate queries
- Enhanced optimization for EXISTS subqueries
- Better handling of LIMIT in compound queries
- Minor improvements to EXPLAIN QUERY PLAN

## Potential Roadblocks
| Change | Risk | Impact |
|--------|------|--------|
| **CROSS JOIN detection** | **Medium** | **select.c, where.c**: Query planner now better detects CROSS JOIN patterns. May reorder joins differently than before, potentially conflicting with Comdb2's join optimization. |
| **LIKE/GLOB optimization** | **Medium** | **func.c, where.c**: New algorithms for pattern matching. Could conflict if Comdb2 has custom LIKE/GLOB implementation. |
| **EXISTS subquery optimization** | **Medium** | **select.c, where.c**: Enhanced EXISTS optimization. May interact with Comdb2's subquery handling. |
| **Aggregate memory improvements** | **Low** | **vdbe.c, select.c**: Better memory management for aggregates. Should be beneficial. |
| **LIMIT in compound queries** | **Low** | **select.c**: Better LIMIT optimization. Low risk. |
