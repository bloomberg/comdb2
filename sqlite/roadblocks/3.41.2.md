# SQLite 3.41.2 Roadblocks

**Release Date:** 2023-03-22

## Changes
- Bug fixes for issues discovered in 3.41.1
- Fix for performance regression in indexed ORDER BY
- Fix for incorrect results with DISTINCT and window functions
- Fix for potential UAF in CREATE TRIGGER
- Security fix for integer overflow

## Potential Roadblocks
| Change | Risk | Impact |
|--------|------|--------|
| **Indexed ORDER BY fix** | **Low** | Performance fix. Should restore expected performance. |
| **DISTINCT with window functions** | **Low** | Correctness fix. Low risk. |

## Action Items
No significant roadblocks expected. This is primarily a bug fix release.

**Recommended**: Important update if using 3.41.x series. Includes security fix and performance restoration.
