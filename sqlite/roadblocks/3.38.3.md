# SQLite 3.38.3 Roadblocks

**Release Date:** 2022-04-27

## Changes
- Bug fixes for issues discovered in 3.38.2
- Fix for incorrect results from the date() function
- Fix for query planner issue with indexes on expressions
- Fix for potential crash in UPSERT with partial indexes
- Fix for FTS5 tokenizer issues

## Potential Roadblocks
| Change | Risk | Impact |
|--------|------|--------|
| **Query planner expression index fix** | **Low** | Bug fix for expression indexes. Should improve correctness. |
| **UPSERT partial index fix** | **Low** | Crash fix. Low risk unless Comdb2 modifies UPSERT heavily. |

## Action Items
No significant roadblocks expected. This is primarily a bug fix release that should be safe to merge.

**Recommended**: Test expression indexes and UPSERT if Comdb2 uses these features.
