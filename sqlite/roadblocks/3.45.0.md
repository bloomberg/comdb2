# SQLite 3.45.0 Roadblocks

**Release Date:** 2024-01-15

## Changes
- **MAJOR:** JSONB binary format introduced (complete JSON subsystem rewrite)
- SQLITE_RESULT_SUBTYPE result code added
- FTS5 tokendata option
- JSON functions rewritten for JSONB support
- New JSON-related opcodes in VDBE

## Potential Roadblocks
| Change | Risk | Impact |
|--------|------|--------|
| JSONB binary format | **CRITICAL** | Complete rewrite of JSON subsystem. Major changes to func.c for JSON functions, vdbe.c for new opcodes, sqliteInt.h for new data structures. This is the most significant change since 3.28.0. Will conflict with any Comdb2 JSON customizations. |
| JSON function rewrites | **CRITICAL** | All JSON functions (json_extract, json_object, etc.) rewritten in func.c. If Comdb2 has customized any JSON functions, conflicts are guaranteed. |
| New VDBE opcodes | High | New opcodes in vdbe.c for JSONB manipulation. Must ensure Comdb2's VDBE modifications accommodate new opcode space. |
| SQLITE_RESULT_SUBTYPE | Medium | New result code in vdbeapi.c, sqliteInt.h. Used for type preservation in JSON. May affect Comdb2's result handling. |
| FTS5 tokendata | Low | FTS5 extension changes. Low risk unless Comdb2 uses FTS5 heavily. |

## Action Items
1. **CRITICAL:** Audit all Comdb2 JSON-related customizations
2. **CRITICAL:** Review complete JSONB implementation changes in func.c
3. Review new VDBE opcodes in vdbe.c and ensure opcode numbering doesn't conflict
4. Check SQLITE_RESULT_SUBTYPE integration in vdbeapi.c
5. Analyze sqliteInt.h for new JSON-related structures (JsonParse, JsonString, etc.)
6. Test all Comdb2 JSON functionality extensively
7. Consider whether to adopt JSONB or maintain text-based JSON
8. Review memory management changes for JSONB allocations
9. Check if Comdb2's type system needs updates for JSONB support
