# SQLite 3.42.0 Roadblocks

**Release Date:** 2023-05-16

## Changes
- **FTS5 trigram tokenizer** - New tokenizer for full-text search
- **CLI enhancements** - Improved command-line shell features
- New SQLITE_DBCONFIG_STMT_SCANSTATUS option
- Query planner improvements for IN operators with large value lists
- Enhanced PRAGMA optimize
- Performance improvements for DATE/TIME functions
- Better error messages for constraint violations

## Potential Roadblocks
| Change | Risk | Impact |
|--------|------|--------|
| **FTS5 trigram tokenizer** | **Low** | **fts5.c**: New tokenizer option for FTS5. No impact unless Comdb2 uses or modifies FTS5. |
| **IN operator optimization (large lists)** | **Medium** | **where.c, expr.c**: Enhanced optimization for IN with many values. May change query plans for large IN lists, potentially conflicting with Comdb2's IN handling. |
| **PRAGMA optimize enhancements** | **Low** | **analyze.c**: Improved PRAGMA optimize. Low risk unless Comdb2 heavily customizes analyze. |
| **DATE/TIME performance** | **Low** | **func.c**: Performance improvements. Should be beneficial. |
| **CLI enhancements** | **None** | Shell only. No impact on library. |
| **Constraint error messages** | **Low** | **insert.c, update.c**: Better error messages. Low risk. |
