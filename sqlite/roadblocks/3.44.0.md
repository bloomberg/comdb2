# SQLite 3.44.0 Roadblocks

**Release Date:** 2023-11-01

## Changes
- concat() scalar function added
- concat_ws() scalar function added
- Aggregate functions with ORDER BY clause support finalized
- Query planner improvements

## Potential Roadblocks
| Change | Risk | Impact |
|--------|------|--------|
| concat() function | Low | New scalar function in func.c. Minimal risk unless Comdb2 has custom concat implementation. |
| concat_ws() function | Low | New scalar function in func.c. Minimal risk unless Comdb2 has custom implementation. |
| Aggregate ORDER BY finalization | High | Further refinements to aggregate ORDER BY handling from 3.43.0. Additional changes to parse.y, select.c, vdbe.c for aggregate compilation and execution. Critical for Comdb2's aggregate processing. |
| Query planner improvements | Medium | Changes to where.c, whereInt.h for optimization. May interact with Comdb2's query planning customizations. |

## Action Items
1. Verify concat() and concat_ws() don't conflict with any Comdb2 custom functions
2. Review aggregate ORDER BY changes in parse.y, select.c, vdbe.c
3. Test Comdb2's aggregate functions with new ORDER BY support
4. Check query planner changes in where*.c files
5. Validate that Comdb2's query optimization logic remains compatible
