# SQLite 3.30.0 Roadblocks

**Release Date:** 2019-10-04

## Changes
- Added support for aggregate window functions (FILTER clause)
- Support for FILTER clause on aggregate queries
- Support for ORDER BY and LIMIT on DELETE and UPDATE statements
- Added the ".filectrl data_version" command to the CLI
- Enhanced optimization of ORDER BY and LIMIT on queries
- Various query planner enhancements

## Potential Roadblocks

| Change | Risk | Impact |
|--------|------|--------|
| Aggregate window functions with FILTER clause | **High** | Affects **parse.y** (grammar changes), **select.c** (query processing), **vdbe.c** (execution). Comdb2's custom query processing may conflict with new aggregate handling. |
| ORDER BY/LIMIT on DELETE/UPDATE | **High** | Modifies **parse.y**, **build.c**, **vdbe.c**. Comdb2's distributed DELETE/UPDATE logic may not support these extensions. Requires careful integration. |
| Query planner enhancements | **Medium** | Changes to **where.c**, **whereInt.h**. May affect Comdb2's custom index selection and query optimization strategies. |
| VDBE opcodes for new features | **Medium** | New opcodes in **vdbe.c** for window functions and filtered aggregates. Need to verify compatibility with Comdb2's VDBE modifications. |

## Action Items

1. **Parse.y Integration**
   - Review grammar changes for FILTER clause syntax
   - Assess ORDER BY/LIMIT extensions on DELETE/UPDATE statements
   - Test Comdb2's custom parsing rules for conflicts

2. **Select.c Window Functions**
   - Analyze window function processing in select.c
   - Verify compatibility with Comdb2's remote query execution
   - Test aggregate FILTER clause with distributed queries

3. **Build.c DELETE/UPDATE Changes**
   - Review code generation for DELETE/UPDATE with ORDER BY/LIMIT
   - Ensure Comdb2's distributed delete/update mechanisms can handle new syntax
   - Add test cases for limited deletes/updates across partitions

4. **VDBE Testing**
   - Identify new opcodes introduced for these features
   - Test window function execution with Comdb2's VDBE modifications
   - Verify opcode compatibility with remote execution

5. **Query Planner Review**
   - Compare where.c changes against Comdb2's query planner customizations
   - Test query plans for new constructs
   - Verify index selection still works correctly
