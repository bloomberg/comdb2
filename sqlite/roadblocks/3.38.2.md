# SQLite 3.38.2 Roadblocks

**Release Date:** 2022-03-26

## Changes
- Bug fixes for issues discovered in 3.38.1
- Fix for issues with PRAGMA integrity_check
- Fix for crash when using aggregate functions in RETURNING clause
- Fix for incorrect results with correlated subqueries
- Fix for memory leak in FTS5

## Potential Roadblocks
| Change | Risk | Impact |
|--------|------|--------|
| **RETURNING clause aggregate fix** | **Low** | Bug fix for RETURNING. Low risk unless Comdb2 heavily modifies RETURNING. |
| **Correlated subquery fix** | **Low** | Query correctness fix. Should improve reliability. |

## Action Items
No significant roadblocks expected. This is primarily a bug fix release that should be safe to merge.

**Recommended**: Test RETURNING clause functionality if Comdb2 uses or modifies this feature.
