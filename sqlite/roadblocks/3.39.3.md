# SQLite 3.39.3 Roadblocks

**Release Date:** 2022-09-05

## Changes
- Bug fixes for issues discovered in 3.39.2
- Fix for query planner regression with indexed expressions
- Fix for incorrect results with NULL values in RIGHT JOIN
- Fix for potential crash in recursive CTEs
- Fix for ALTER TABLE issues

| Change | Risk | Impact |

| **RIGHT JOIN NULL handling fix** | **Low** | Correctness fix for NULL semantics in RIGHT JOIN. |
| **Query planner indexed expression fix** | **Low** | Performance fix. Should be beneficial. |
