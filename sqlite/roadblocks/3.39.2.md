# SQLite 3.39.2 Roadblocks

**Release Date:** 2022-07-21

## Changes
- Bug fixes for issues discovered in 3.39.1
- Fix for incorrect results with FULL OUTER JOIN and ON clause

- Fix for potential UAF in window functions

| Change | Risk | Impact |

No significant roadblocks expected. This is primarily a bug fix release.
