# SQLite 3.39.1 Roadblocks

**Release Date:** 2022-07-13

## Changes
- Bug fixes for issues discovered in 3.39.0
- Fix for incorrect results with RIGHT JOIN and WHERE clause
- Fix for assertion failure in FULL OUTER JOIN
- Fix for query planner issue with OR clauses
- Fix for potential crash in aggregate functions

## Potential Roadblocks
| Change | Risk | Impact |
|--------|------|--------|
| **RIGHT JOIN WHERE clause fix** | **Low** | Critical bug fix for new JOIN types. Essential if adopting 3.39.x. |
| **FULL OUTER JOIN assertion fix** | **Low** | Stability fix for new JOIN feature. |

## Action Items
No significant roadblocks expected. This is primarily a bug fix release that addresses issues with the new JOIN types introduced in 3.39.0.

**Recommended**: If adopting 3.39.x series, this release is essential as it fixes critical bugs in RIGHT and FULL OUTER JOIN.
