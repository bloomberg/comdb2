# SQLite 3.41.1 Roadblocks

**Release Date:** 2023-03-10

## Changes
- Bug fixes for issues discovered in 3.41.0
- Fix for query planner regression with LEFT JOIN
- Fix for incorrect results with aggregate functions in HAVING clause
- Fix for potential crash in window functions
- Fix for memory leak in error handling

## Potential Roadblocks
| Change | Risk | Impact |
|--------|------|--------|
| **LEFT JOIN query planner fix** | **Low** | Bug fix for query planner. Should improve correctness. |
| **HAVING clause aggregate fix** | **Low** | Correctness fix for aggregates. Low risk. |

## Action Items
No significant roadblocks expected. This is primarily a bug fix release.

**Recommended**: Standard bug fix update if using 3.41.x series. Fixes important query planner regression.
