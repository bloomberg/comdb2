# SQLite 3.29.0 Roadblocks

**Release Date:** 2019-07-10

## Summary

First release after Comdb2's current SQLite 3.28.0 base.

## Changes

1. **SQLITE_DBCONFIG_DQS_DML and SQLITE_DBCONFIG_DQS_DDL** - New configuration options for double-quoted string literals
2. **SQLITE_DQS=0 recommended** - Double-quoted strings as identifiers recommended
3. **Query planner improvements** - AND/OR optimization, LIKE optimization for numeric affinity
4. **sqlite_dbdata virtual table** - For extracting raw content from databases
5. **Rounding behavior improvements** - round() function behavior changes
6. **CLI enhancements** - .recover, .filectrl, .dbconfig commands

## Potential Roadblocks

### Low Risk

| Change | Impact | Notes |
|--------|--------|-------|
| DQS configuration options | Low | Comdb2 has its own quoting handling |
| Query planner AND/OR optimization | Low | May affect query plans, test thoroughly |
| LIKE optimization changes | Low | Comdb2 disables BLOB matching in LIKE anyway |

### No Expected Roadblocks

- rounding() changes are behavioral, not structural
- CLI changes don't affect library code
- sqlite_dbdata is optional extension

## Action Items

1. Test query plans with AND/OR expressions
2. Verify double-quoted string handling works correctly
