# SQLite 3.47.0 Roadblocks

**Release Date:** 2024-10-21

## Changes
- Performance optimizations for query planner
- WHERE clause optimization improvements
- Index selection improvements
- Subquery flattening enhancements

## Potential Roadblocks
| Change | Risk | Impact |
|--------|------|--------|
| Query planner optimizations | Medium | Changes to where.c, whereInt.h for improved query planning. May conflict with Comdb2's custom query optimization logic. |
| WHERE clause improvements | Medium | Modifications to where*.c files for better predicate handling. Could affect Comdb2's query execution. |
| Index selection changes | Medium | Alterations to index selection logic in where.c. May interact with Comdb2's distributed index management. |
| Subquery flattening | Medium | Changes to select.c for subquery optimization. Could conflict with Comdb2's distributed query handling. |

## Action Items
1. Review query planner changes in where.c and whereInt.h
2. Test Comdb2's query optimization with new planner improvements
3. Check subquery flattening changes in select.c
4. Verify index selection works correctly with Comdb2's distributed indices
5. Run performance benchmarks to ensure optimizations don't regress Comdb2 queries
