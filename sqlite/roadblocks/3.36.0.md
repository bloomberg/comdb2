# SQLite 3.36.0 Roadblocks

**Release Date:** 2021-06-18

## Changes
- Enhanced EXPLAIN QUERY PLAN output with more detail
- Query planner improvements for RIGHT and FULL OUTER JOIN
- Improvements to bytecode generation
- Enhanced ALTER TABLE validation
- Optimization improvements for aggregate queries

## Potential Roadblocks

| Change | Risk | Impact |
|--------|------|--------|
| EXPLAIN QUERY PLAN enhancements | Low | Changes to **vdbe.c** and query planner. Should not conflict with Comdb2 modifications but output format may differ from expectations. |
| RIGHT/FULL OUTER JOIN improvements | Medium | Changes to **select.c** and **where.c**. May interact with Comdb2's join optimization logic. |
| Bytecode generation changes | Medium | Modifications to **vdbe.c** and code generator. Could affect Comdb2's execution model if custom bytecode operations exist. |
| Aggregate query optimizations | Medium | Changes to **select.c** and **vdbemem.c**. May conflict with Comdb2's aggregate handling or memory management. |

## Action Items

1. **EXPLAIN QUERY PLAN Review**
   - Test EXPLAIN output with Comdb2 queries
   - Verify no regression in query plan quality
   - Update any tools/scripts that parse EXPLAIN output

2. **JOIN Optimization Testing**
   - Validate RIGHT and FULL OUTER JOIN behavior
   - Regression test Comdb2's join operations
   - Performance benchmark join-heavy workloads

3. **Bytecode Compatibility**
   - Review vdbe.c changes for conflicts with Comdb2 customizations
   - Test execution model compatibility
   - Verify no breaking changes to bytecode format

4. **Aggregate Query Validation**
   - Test aggregate functions with Comdb2's memory management
   - Verify vdbemem.c changes don't conflict with Comdb2's value handling
   - Performance test aggregate-heavy queries

5. **Integration Testing**
   - Run full Comdb2 test suite
   - Focus on complex queries with joins and aggregates
