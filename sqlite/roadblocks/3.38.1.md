# SQLite 3.38.1 Roadblocks

**Release Date:** 2022-03-12

## Changes
- Bug fixes for issues discovered in 3.38.0
- Fix for VACUUM on tables with columns renamed by ALTER TABLE
- Fix for query planner issue with complex LEFT JOINs
- Fix for potential UAF in BTREEINFO pragma
- Fix for assertion failures in window functions

## Potential Roadblocks
| Change | Risk | Impact |
|--------|------|--------|
| **Query planner LEFT JOIN fix** | **Low** | Minor correction to query planner logic. Should be beneficial for Comdb2. |
| **VACUUM column rename fix** | **Low** | Bug fix for ALTER TABLE interaction. Low risk. |

## Action Items
No significant roadblocks expected. This is primarily a bug fix release that should be safe to merge.

**Recommended**: Review the query planner fixes to ensure they don't regress any Comdb2-specific optimizations.
